# Jarvis visual system

## Authority
User pinned the complete dashboard world and experience to the supplied video, especially its Network view. No alternate visual direction requested.

## Shell
Light neutral sidebar, 216px wide at desktop; charcoal #171817 canvas; pink #eaa1b7 primary action and neural core; soft gray navigation and fine dividers. Compact Inter type, 12–14px interface copy. Network is the initial screen, with Dashboard, Talk, Workflows, Files, Connections, Assistant, Account navigation in the video's order.

## Signature
An animated pink neural core with radial service nodes and green connection paths. Connected states must reflect real capabilities. The network is navigable: selecting an app opens its connection flow. A compact live transcript and text/voice composer sit at the bottom.

## Mode
Operate. Keyboard accessible controls, responsive sidebar drawer, reduced motion, visible connection/errors/loading states. Preserve this world across all secondary views.
