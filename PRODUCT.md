# Jarvis
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
The owner operates a Windows computer and wants Indonesian voice and text commands to perform tasks across desktop applications and connected services.

## Product Purpose
A working personal voice assistant, app integrations, conversation history, and local computer control.

## Operating Context
Existing Next.js 14 app running locally on Windows. Preserve dummy login. User selected an OpenAI-compatible API.

## Capabilities and Constraints
User supplies provider credentials and account connections. Display actual connection and execution states. Do not claim every possible command is supported. Desktop commands run only on the local host and require explicit enablement in settings.

## Brand Commitments
Match the Jarvis demonstration at https://www.youtube.com/watch?v=YCkVtEoWYU8 as closely as the observed frames allow. Build the dashboard rather than a marketing landing page.
